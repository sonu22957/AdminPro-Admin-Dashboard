# 🚀 AdminPro – Admin Dashboard

A modern, responsive and interactive Admin Dashboard built using React.js. AdminPro provides a clean interface to manage users, orders, analytics and application settings.

## 🌟 Features

* 📊 **Dashboard Overview** – Revenue, users, orders and products statistics.
* 👥 **User Management** – Add, search and delete users.
* 🛒 **Order Management** – Search orders, filter by status and update order status.
* 📈 **Analytics Dashboard** – Revenue charts and category-wise statistics.
* ⚙️ **Settings Page** – Admin profile and settings interface.
* 🌙 **Dark / Light Mode** – Switch between themes.
* 📱 **Responsive Design** – Mobile-friendly sidebar and navigation.
* 💾 **Theme Persistence** – Saves theme preference using LocalStorage.

## 🛠️ Tech Stack

## ⚙️ Installation & Setup

**1. Clone the repository**

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Navigate to the project folder**

```bash
cd vite-project
```

**3. Install dependencies**

```bash
npm install
```

**4. Start the development server**

```bash
npm run dev
```

Open the local URL shown in your terminal.
